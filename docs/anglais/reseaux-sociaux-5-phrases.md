# Anglais – Les réseaux sociaux : 5 phrases contre les réseaux sociaux

Niveau : 9e année  
Thème : Social media

## En français

1. Les réseaux sociaux font perdre du temps.
2. Ils peuvent rendre les élèves dépendants.
3. Ils peuvent perturber les études.
4. Ils exposent les utilisateurs au cyberharcèlement.
5. Ils réduisent parfois les échanges en famille.

## In English

1. Social media wastes time.
2. It can make students addicted.
3. It can disturb studies.
4. It exposes users to cyberbullying.
5. It sometimes reduces family communication.

## Vocabulaire utile

- Social media : les réseaux sociaux
- To waste time : perdre du temps
- Addicted : dépendant(e)
- Studies : les études
- Cyberbullying : le cyberharcèlement
- Family communication : les échanges en famille
